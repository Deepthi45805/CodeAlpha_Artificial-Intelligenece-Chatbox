🤖 Artificial Intelligence Chatbot (Java)

📌 Project Description

The Artificial Intelligence Chatbot is a Java-based console application designed for interactive communication. It uses basic Natural Language Processing (NLP) techniques and rule-based logic to respond to user queries.

---

🚀 Features

- 💬 Interactive Chat Interface
- 🧠 Rule-Based NLP Responses
- ⚡ Real-Time User Interaction
- 🔁 Continuous Chat Loop Until Exit
- 🧩 Easy To Extend With More Responses

---

🛠️ Technologies Used

- Java
- OOP Concepts
- String Processing (NLP Basics)
- Console-Based Interface

---

▶️ How To Run

1. Install Java (JDK)
2. Open Terminal / Command Prompt
3. Compile The Program:
   javac Chatbox.java
4. Run The Program:
   java Main

👉 If Using Online Compiler (Like Programiz), Ensure Class Name Is Main
